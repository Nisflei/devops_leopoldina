🚀 DevOps TB

Projeto desenvolvido para estudos e práticas de DevOps, versionamento de código e manutenção de aplicações utilizando Git e GitHub.

📋 Sobre o projeto

O devops_tb é um projeto utilizado para atividades práticas relacionadas ao desenvolvimento e aos conceitos de DevOps.

Atualmente, o projeto possui uma página HTML simples utilizada para demonstrar alterações e atualizações no código durante o processo de desenvolvimento e manutenção.

🛠️ Tecnologias utilizadas
HTML5
Git
GitHub
📁 Estrutura do projeto
devops_tb/
├── .github/
│   └── pull_request_template.md
├── index.html
└── README.md

▶️ Como executar o projeto
1. Clone o repositório
git clone https://github.com/Nisflei/devops_tb.git

2. Acesse a pasta do projeto
cd devops_tb

3. Execute o projeto

Como o projeto atualmente é composto por HTML, basta abrir o arquivo index.html diretamente no navegador.

Também é possível utilizar uma extensão como o Live Server no VS Code para executar a página durante o desenvolvimento.

🔄 Fluxo de desenvolvimento

O projeto utiliza Git e GitHub para controle de versão.

Fluxo sugerido:

Criar branch
     ↓
Desenvolver
     ↓
Testar
     ↓
Commit
     ↓
Push
     ↓
Pull Request
     ↓
Code Review
     ↓
Merge

Exemplo
git checkout -b feature/minha-alteracao

git add .

git commit -m "feat: adiciona nova alteração"

git push origin feature/minha-alteracao


Depois, deve ser aberto um Pull Request no GitHub para revisão das alterações.

🧪 Testes

Como o projeto atualmente possui uma página HTML estática, os testes podem ser realizados diretamente pelo navegador.

Antes de abrir um Pull Request, verifique:

 A página abre corretamente
 As alterações aparecem conforme esperado
 Não existem erros no console do navegador
 O código foi revisado
 O commit possui uma mensagem clara
🤝 Contribuição

Para contribuir com o projeto:

Faça um fork ou clone o repositório.
Crie uma nova branch.
Faça suas alterações.
Teste localmente.
Realize o commit.
Envie a branch para o GitHub.
Abra um Pull Request.
